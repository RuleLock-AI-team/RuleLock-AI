# Contributing

## Branches
- `main` is protected — no direct pushes.
- Branch per task: `feature/<component>-<short-description>`, e.g. `feature/rule-engine-cod-caps`.

## Pull requests
- One approval required before merging into `main`.
- Keep PRs scoped to your own component — makes review and individual-contribution tracking easier for the report/viva.

## Commits
- Write commit messages that describe *what changed and why* — these double as evidence for the development logbook.
